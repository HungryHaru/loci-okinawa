# 沖縄 記憶の宮殿

> 詳しい使い方は [help.html](help.html)（アプリ右上の「？」）を見てください。

Google ストリートビューで沖縄を歩きながら、場所法（記憶の宮殿）のルートを作って復習するための自分用 Web アプリです。

## 機能
- **作成**：ストリートビューで場所を探し、「覚えること」と「連想イメージ」を置く（位置・向き・ズームも保存）
- **復習**：ルートの順に場所を巡り、思い出す → 答え合わせ → 覚えてた／忘れたを記録
- **一覧**：確認・編集・並べ替え・削除
- 宮殿（ルート）はいくつでも作れる
- データはブラウザ内（localStorage）に保存。メニューから JSON でバックアップ／読み込みができる

## セットアップ

### 1. API キーを作る（初回だけ）
1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作る（請求先アカウントの設定が必要）
2. 「API とサービス」→「ライブラリ」で次の2つを有効にする
   - **Maps JavaScript API**（地図・ストリートビュー）
   - **Places API (New)**（場所の検索）※「(New)」の付いている方
3. 「認証情報」→「認証情報を作成」→「API キー」
4. キーの制限を設定する（大事）
   - アプリケーションの制限：**ウェブサイト** → `http://localhost:8000/*`
   - API の制限：**Maps JavaScript API** と **Places API (New)**

### 2. 無料で使い続けるために（おすすめ）
- 「API とサービス」→ Maps JavaScript API →「割り当て」で、**1日あたりの上限**を低めに設定する
  （例：地図の読み込みとストリートビュー、それぞれ 1日 100 回程度）。上限を超えると止まるだけで課金されません。
  Places API (New) の「Text Search」も同じように 1日 50 回程度にしておくと安心です（検索は Enter を押したときだけ実行されます）。
- 「お支払い」→「予算とアラート」で少額（例：100円）の予算アラートを設定しておくと安心。
- 無料枠の回数は変更されることがあるので、[公式の料金ページ](https://developers.google.com/maps/billing-and-pricing/pricing) で確認してください。

### 3. 起動
```
cd C:\Users\HARUKI\projects\loci-okinawa
python -m http.server 8000
```
ブラウザで http://localhost:8000 を開き、API キーを入力する。

## 注意
- 規約上、ストリートビューの画像そのものは保存していません（位置・向き・パノラマ ID だけを保存）。
- ブラウザのデータを消すと宮殿も消えるので、ときどき「バックアップを保存」してください。

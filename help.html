1. このアプリについて

場所法（記憶の宮殿）は、よく知っている道や建物の「場所」に、覚えたいものを順番に置いていく記憶術です。思い出すときは、頭の中でその道を歩き、置いたものを拾っていきます。

このアプリでは、Google ストリートビューを使うことで、行ったことのない沖縄の場所でも「宮殿」にできます。頭の中のイメージがぼやけてきたら、実際の景色を見て確かめられます。

  • 宮殿：1つのテーマ用のルート（例：「英単語セット1」「首里城ルート」）
  • 場所：ルート上の地点。覚えたいものを1つずつ置く

2. はじめての準備

API キーを作る（初回だけ）

  1. Google Cloud Console でプロジェクトを作り、請求先アカウントをリンクします（リンクしないとストリートビューが白黒になります）。
  2. 「API とサービス」→「ライブラリ」で Maps JavaScript API と Places API (New) を有効にします。
  3. 「認証情報」→「API キー」を作り、制限をかけます。
    • ウェブサイトの制限：http://localhost:8000/*（スマホで使うときは、そのアドレスも追加）
    • API の制限：Maps JavaScript API と Places API (New)
💰 無料のまま使うために：各 API の「割り当て」で 1日あたりの上限を低めに設定しておきましょう（例：地図とストリートビュー 1日 100 回、検索 1日 50 回）。上限に達すると止まるだけで、料金はかかりません。「予算とアラート」で少額のアラートも設定しておくと安心です。

起動する

cd C:\Users\HARUKI\projects\loci-okinawa
python -m http.server 8000

ブラウザで http://localhost:8000 を開き、API キーを入力します。

3. 基本の流れ

  1. 宮殿を作る：右上の ＋ で名前を付けて作ります。
  2. 場所を探す：左上の検索、地図のクリック、ストリートビューの矢印で歩いて探します。シーサー、看板、ガジュマルなど目立つ目印を画面の真ん中に入れます。
  3. 覚えることを置く：「覚えること」と「連想イメージ」を書き、必要なら落書きやAI画像を貼って、「この場所に置く」を押します。押した瞬間に自動で保存されます。
  4. 次の場所へ歩く：道に沿って少し進み、2〜3 を繰り返します。
  5. 復習する：「復習」タブで順番に巡り、思い出してから答え合わせをします。

6. AI画像の作り方

  1. 「連想イメージ」に場面を書きます。
    例：シーサーの口から巨大なりんごがゴロゴロ転がり出てくる
  2. 「🎨 Claudeで絵を作る」を押します。指示文がコピーされ、Chrome で Claude が開きます。
  3. Claude に貼り付けて送信すると、画面の横に絵が表示されます。直したい所があれば「りんごをもっと大きく」のように言葉で頼みます。
  4. 絵が決まったら、Claude の返事の最後にあるコードの右上の「コピー」（コピーのマーク）を押します（中身は SVG コードですが、見なくて大丈夫です）。
    右側に開いた絵の画面の「コピー」でも同じものがコピーできます。
  5. アプリに戻って「📋 コピーした絵を貼る」を押し、景色の貼りたい所をクリックします（ドラッグで大きさ）。

ほかの画像生成AI（Microsoft Copilot、ChatGPT、Gemini など）を使うときは、ヒント欄の「こちらの指示文」でコピーした文を貼って画像を作り、できた画像を景色の上で Ctrl+V、または保存したファイルを景色にドラッグします。

白い背景は自動で透明になり、ステッカーのようになります（四隅とつながった白い部分だけが消えるので、絵の中の白は残ります）。画像は小さく縮小して保存するので、たくさん貼っても大丈夫です。

7. 復習のしかた

  • 今日の復習：今日が復習日の場所だけを巡ります。ふだんはこれを使います。
  • 最初から順に：ルートの1番から順に巡ります。
  • 苦手・未復習だけ：前回「忘れた」場所と、まだ一度も復習していない場所だけを巡ります。

答えを見る前に、景色の中に置いたイメージを頭の中ではっきり思い浮かべてから「答えを見る」を押しましょう。押すと、答えと一緒に落書き・付箋・画像が景色の上に現れます。

キーボード：Enter 答えを見る ／ 1 覚えてた ／ 2 忘れた

目印の名前

場所を置くときに「目印の名前」（例：赤いポスト、知念商店）を付けておくと、一覧・復習・地図のピン・LINE の通知・Obsidian のノートに表示されます。「#3」だけより、どの場所か思い出しやすくなります。前に置いた場所は、一覧の「編集」から付けられます。

日本語 → 英語で出題する

英語のフレーズを覚えるときは、場所と一緒に日本語の問題を出せます。「🇯🇵「〜することになっている」を英語で言うと？」と出るので、英語を声に出してから「答えを見る」を押します。

  • 問題は、場所を置くときの「日本語の問題」欄に書きます。
  • 空のときは、「覚えること」の最後の（ ）の中を自動で使います。例：I'm supposed to 〜（〜することになっている） → 「〜することになっている」
  • 場所だけで思い出す練習をしたいときは、復習タブの「日本語の問題を出す」のチェックを外します（端末ごとに覚えています）。
  • LINE の通知と、Obsidian の復習カード（「〜」を英語で::答え）にも、同じ問題が入ります。

復習日の決まり方（忘却曲線）

「覚えてた」が続くほど、次の復習までの間がのびます：1日 → 3日 → 1週間 → 2週間 → 1か月 → 2か月 → 4か月。「忘れた」を押すと、翌日からやり直しです。

  • 置いたばかりで、まだ復習していない場所は「今日」が復習日です。
  • 復習日より前に復習して「覚えてた」でも、間はのびません（同じ日に何回やっても進みません）。
  • 復習日を過ぎた場所は、復習するまで毎日「今日の復習」に残ります。

8. Obsidian 連携

PC の Chrome で使います（デスクトップのアイコンから開くと Chrome で開きます）。

  1. 🔗 を押し、OneDrive\ドキュメント\Obsidian Vault を選んで、書き込みを許可します。
  2. この後は、場所を置く・編集する・復習するたびに、約1.5秒後に自動で Vault に保存されます。
  3. アプリを開き直すと、最初にどこかをクリックしたときに書き込みの確認が出ます。「毎回のアクセスで許可する」を選ぶと、次からは確認なしでつながったままになります（「今回のみ許可」だと開くたびに確認が出ます）。
Obsidian Vault/
└─ 記憶の宮殿/
   ├─ 首里城ルート.md   … 宮殿ごとに1つのノート
   ├─ 画像/            … 貼った画像
   └─ _data.json       … アプリのデータ全体（復元用）

ノートには、覚えたこと、連想イメージ、付箋の文字、画像、「ストリートビューで開く」リンク（同じ地点・同じ向きで開きます）、正解・不正解の回数が書かれます。

Obsidian のコミュニティプラグイン Spaced Repetition を入れると、ノートの 質問::答え の行がそのまま復習カードになります。

⚠ アプリ → Obsidian の一方通行です。Obsidian で「記憶の宮殿」フォルダのノートを書き換えても、次の保存でアプリの内容に上書きされます。メモを足したいときは、別のノートを作ってリンクしてください。

8-2. クラウド連携（PC とスマホの同期・LINE 通知）

自分の Google Apps Script（Google の無料のしくみ）を1つ用意すると、次の2つができます。

  • PC とスマホの同期：宮殿のデータと貼った画像を、自分の Google ドライブに置いて、どの端末からも同じ内容を使えます。
  • LINE で復習のお知らせ：毎日 12 時ごろ、今日の復習がある日だけ LINE に届きます（PC の電源が切れていても届きます）。同期を使っていれば、問題（その場所の景色を開くリンク）と答えも載ります。
  • 毎日の自動バックアップ：同じ時間に、Google ドライブへ 7 日分のバックアップを取ります。

データは自分の Google ドライブの「沖縄 記憶の宮殿（同期データ）」フォルダに入ります（消さないでください）。合言葉を知らないと読み書きできません。ストリートビューの景色は保存しません（今までどおり、場所と向きだけです）。

ぜんぶ無料です（LINE は月 200 通まで無料。1日1通なので収まります）。

① LINE の準備（自分専用の公式アカウントを作る）

  1. LINE 公式アカウントの作成ページで、自分の LINE でログインして、アカウントを作ります（名前は「記憶の宮殿」など。業種などは適当でOK）。
  2. LINE Official Account Manager で作ったアカウントを開き、右上の「設定」→「Messaging API」→「Messaging API を利用する」を押します（プロバイダー名は自分の名前などでOK）。
  3. 同じ画面の「応答設定」で「応答メッセージ」をオフにしておくと、話しかけても自動返信が来なくなります（なくてもOK）。
  4. LINE Developers コンソールを開き、プロバイダー → 作ったチャネルを選びます。
    • 「チャネル基本設定」の一番下にある「あなたのユーザーID」（U から始まる）を控えます。
    • 「Messaging API 設定」の QR コードをスマホで読んで、友だちに追加します。
    • 同じページの一番下の「チャネルアクセストークン（長期）」で「発行」を押し、出てきた長い文字を控えます。

② Google Apps Script の準備

  1. Google Apps Script を開き、「新しいプロジェクト」を押します。左上の名前を「記憶の宮殿 LINE 通知」などに変えます。
  2. 最初からある文字を全部消して、アプリのフォルダの gas\line-notify.gs の中身をまるごと貼り付け、保存（💾）します。
  3. 左の ⚙「プロジェクトの設定」→ 一番下の「スクリプト プロパティを追加」で、次の3つを入れて保存します。
    • LINE_TOKEN：①で控えたチャネルアクセストークン
    • LINE_USER_ID：①で控えたユーザーID
    • SECRET：自分で決めた合言葉（英数字 20 文字くらい。例：okinawa7x9k2m4p8q1z5w3 のような適当な文字）
  4. 左の「<> エディタ」に戻り、上の関数の選択を setup にして「▶ 実行」を押します。
    • 「承認が必要です」と出たら、自分のアカウントを選び、「詳細」→「（安全ではないページ）に移動」→「許可」と進みます（自分で作ったスクリプトなので大丈夫です）。
  5. 右上の「デプロイ」→「新しいデプロイ」→ 歯車で「ウェブアプリ」を選びます。
    • 次のユーザーとして実行：自分
    • アクセスできるユーザー：全員（合言葉がないと受け付けないので大丈夫です）
    「デプロイ」を押して、出てきたウェブアプリの URL（…/exec で終わる）をコピーします。

③ アプリにつなぐ

  1. アプリの「⋯」→「クラウド連携の設定（同期・LINE 通知）」を押します。
  2. コピーした URL の最後に ?key=合言葉 を付けて貼り、OK を押します。
    例：https://script.google.com/macros/s/AKfy…/exec?key=okinawa7x9k2m4p8q1z5w3
  3. 「LINE にテスト通知を送りますか？」で OK を押し、LINE に「テスト：…通知が届きました」と届けば完了です。
  4. スマホなど、ほかの端末でも同じ URL を設定します（URL は LINE で自分に送るとコピーしやすいです）。テスト通知は送らなくて大丈夫です。

この後は、場所を置く・編集する・復習するたびに、約2秒後に自動でクラウドに保存されます。アプリを開いたときや、アプリに戻ってきたときに、ほかの端末での変更を読み込みます。

同期のしくみと注意

  • 初めて設定した端末のデータがクラウドに入ります。まず PC で設定し、そのあとスマホで設定すると、スマホに PC のデータが入ります。
  • スマホにもデータがある状態で設定すると、「どちらのデータを使うか」を聞かれます。OK＝クラウド（PC）のデータを使う、キャンセル＝この端末のデータでクラウドを上書きする、です。
  • 電波のない所で使った変更は、次にネットにつながったときに送られます。
  • PC とスマホの両方で、同期する前に変更した場合も、どちらを残すか聞かれます。こまめに同期されるので、ふだんはまず起きません。
  • Obsidian 連携は PC だけです。スマホでの変更も、PC でアプリを開いたときに読み込まれて、Vault に書き出されます。

LINE の文面

上に問題（「#3」などの場所の番号、日本語の問題があればそれ、その場所の景色を Google マップで開くリンク）、少しスクロールした下に答えが載ります。リンクで景色を見て、置いたものを思い出してから、下にスクロールして答え合わせをします。一度に載るのは 15 か所までです。

アプリで「今日の復習」をすると、覚えてた／忘れたが記録されて、次の復習日が決まります（LINE だけで答え合わせした分は記録されません）。

バックアップから戻す

  1. 「⋯」→「クラウドのバックアップから戻す」を押します。
  2. 日付の一覧が出るので、戻したい日の番号を入れます（その日の 12 時ごろの内容です）。
  3. 確認で OK を押すと、その内容に戻ります。PC もスマホも、次に開いたときにその内容になります。

バックアップは Google ドライブの「沖縄 記憶の宮殿（同期データ）」→「backups」フォルダにあり、古いものから自動で消えます（7 日分）。

前に LINE 通知だけ設定していた場合（Apps Script の更新）

  1. Apps Script のエディタで、今のコードを全部消し、新しい gas\line-notify.gs の中身を貼り付けて保存（💾）します。
  2. 関数 testLine を選んで「▶ 実行」します（LINE の文面を今すぐ試したいときは testDaily）。Google ドライブの許可を求められるので、「詳細」→「（安全ではないページ）に移動」→「許可」と進みます。実行ログに「同期データのフォルダ：…」と出れば OK です。
  3. 「デプロイ」→「デプロイを管理」→ 鉛筆マーク →「バージョン」を「新バージョン」にして「デプロイ」を押します（「新しいデプロイ」ではなく、こちら。URL が変わりません）。
  4. PC のアプリで「⋯」→「クラウド連携の設定」を開き、URL はそのままで OK を押します。続けてスマホでも同じ URL を設定します。
💡 予定が送られるのはアプリを使ったときだけです。しばらくアプリを開かなくても、送られた予定で毎日お知らせは届きます（復習日を過ぎた場所も数に入ります）。

9. データの保存

  • 保存ボタンはありません。置く・編集する・並べ替える・復習する・描くたびに、自動で保存されます。
  • データは、ブラウザの中の大容量の保存領域（IndexedDB）に保存しています。数百〜数千か所、画像も数百枚くらいなら問題ありません。
  • アプリは、ブラウザに「容量不足になっても消さないで」とお願いしています。お願いが通ったかどうかは「⋯ → 保存状況を見る」で確認できます。
  • データはブラウザごと・端末ごとに保存されます。PC とスマホで同じデータを使うには、クラウド連携を設定します。

バックアップ

  • Obsidian 連携をしていれば、自動でバックアップされます（Vault は OneDrive の中にあるので、クラウドにも残ります）。
  • 手動でバックアップするときは「⋯ → バックアップを保存」を使います。画像も含めて1つの JSON ファイルになります。
  • 復元するときは「⋯ → バックアップを読み込む」で、バックアップの JSON か、Vault の _data.json を選びます（_data.json には画像が含まれませんが、画像は Vault の「画像」フォルダに残っています）。
⚠ ブラウザの「閲覧データを削除」で「Cookie とサイトデータ」を消すと、アプリのデータも消えます。

10. スマホで使う

アプリはネット上にも置いてあるので、スマホからも開けます（PC の電源が切れていても使えます）。

https://hungryharu.github.io/loci-okinawa/

  1. スマホのブラウザで上のアドレスを開き、API キーを入力します（PC と同じキーで OK）。
  2. ブラウザのメニューから「ホーム画面に追加」すると、アプリのように開けます。

API キーは、アプリのファイルには書かれていません（各ブラウザで入力する）。アドレスを知っている人がアプリを開いても、あなたのキーやデータは見えません。キーの「ウェブサイトの制限」には https://hungryharu.github.io/loci-okinawa/* を入れてあります。

スマホで使うときの注意点

注意点内容・対策
データを PC とそろえるクラウド連携を設定すると、自動で同期されます。設定しない場合は、PC で「バックアップを保存」した JSON をスマホに送り、「バックアップを読み込む」で移します（中身は置き換わります）。
Obsidian 連携ができないスマホのブラウザは、フォルダへの書き込みに対応していません。Obsidian 連携は PC で行ってください。
iPhone はデータが消えることがあるSafari では、しばらく開かないサイトのデータが消されることがあります。「ホーム画面に追加」して、そこから開くと消されにくくなります。こまめにバックアップしてください。
モバイルデータ通信を多く使うストリートビューの画像は容量が大きいので、できるだけ Wi-Fi で使いましょう。
無料枠を早く使うPC と同じキーを使うと、回数は合算されます。歩くたびに読み込みが発生するので、1日の上限を設定しておきましょう。
画像の貼り方スマホでは Ctrl+V やドラッグができないので、🖼 から写真やファイルを選んで貼ります。
描くときの操作✏️ を選んでいる間は、指でなぞると線になり、視点は動きません。視点を動かすときは ✋ に戻します。
画面が狭い上がストリートビュー、下が操作パネルになります。地図は「拡大」で大きくできます。横向きにすると景色を広く見られます。

11. 困ったとき

ストリートビューが白黒・暗い

Google 側の設定の問題です。請求先アカウントのリンク、API の有効化、キーの制限を確認してください。ブラウザで F12 → Console を開くと、エラー名（BillingNotEnabledMapError など）が出ています。

検索できない

Places API (New) が有効か、キーの API の制限に入っているかを確認してください。

保存した場所の景色が少し違う

Google がストリートビューの写真を新しくすると、保存した写真が使えなくなることがあります。その場合は、近くの新しい写真に自動で切り替わります。向きや落書きの位置がずれたら、一覧の「編集」→「位置を今の画面に変更」で直してください。

落書きが見えない

保存したときと同じ地点にいるか確認してください。一覧の「見る」で、その地点に戻れます。復習中は「答えを見る」を押すまで表示されません。

LINE にテスト通知が届かない

  • まず Apps Script のエディタで関数 testLine を選んで「▶ 実行」してみてください。届けば LINE 側は OK で、アプリ → Apps Script のつなぎ方の問題です。届かなければ、下の「実行ログ」に原因が出ます。
  • LINE で、作った公式アカウントを友だちに追加しているか確認してください。
  • URL の最後の ?key= の後ろが、スクリプト プロパティの SECRET とまったく同じか確認してください。
  • Apps Script の左の「実行数」でエラーが出ていないか見てください。「LINE への送信に失敗：401」ならトークンの貼り間違い、「400」ならユーザーIDの貼り間違いです。
  • Apps Script のコードを書き換えたときは、「デプロイ」→「デプロイを管理」→ 鉛筆 →「バージョン：新バージョン」→「デプロイ」をしないと反映されません。

🔗 が黄色のまま

1回押して、書き込みを「許可」してください。それでも直らないときは「⋯ → Obsidian 連携を解除」してから、もう一度 🔗 で Vault を選び直してください。

12. 場所法のコツ

  • イメージは大げさに、変に、動きをつけて。「りんごが置いてある」より「シーサーがりんごを吐き出して、通行人に当たっている」の方が覚えやすくなります。
  • 目印のはっきりした場所を選ぶ。似たような道が続く場所より、角の店、鳥居、大きな木など、見分けやすい場所が向いています。
  • 1つの場所に1つ。詰め込みすぎると混ざります。
  • 一方向に歩く。行ったり来たりせず、道に沿って進むと順番を思い出しやすくなります。
  • 1つの宮殿は10〜20か所くらい。多くなったら、宮殿を分けましょう（例：「国際通り」「首里」「北谷」）。
  • 忘れかけたころに復習する。覚えた当日、翌日、3日後、1週間後……と、間隔を広げていくと長く残ります。
  • ときどき目を閉じて歩く。アプリを見ずに頭の中だけでルートを歩けるか試すと、本当の力がつきます。
